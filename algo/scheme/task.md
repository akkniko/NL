Прочитать два целых числа и найти их наибольший общий делитель по алгоритму Евклида, используя рекурсивную функцию.

**Требования:**
- не использовать готовую функцию НОД;
- результат должен быть неотрицательным;
- предусмотреть отрицательные входные числа и случай, когда одно из чисел равно нулю; для `(0, 0)` вывести понятное сообщение, так как НОД в этом случае не определён.

**Пример:** `48 18` → `6`.
