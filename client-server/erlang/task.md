Реализовать TCP-сервер, который принимает одну строку. Если клиент прислал `PING`, сервер отвечает `PONG`; в остальных случаях отвечает `ERROR: expected PING`. Клиент подключается к `127.0.0.1`, отправляет `PING`, получает ответ и выводит его.

**Требования:** использовать `gen_tcp` из стандартной поставки Erlang, завершать сокеты после обмена и выводить понятное сообщение, если сервер недоступен.

**Проверка:** обычный запрос `PING` должен получить ответ `PONG`.
