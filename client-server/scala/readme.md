# Как запустить:

Нужно открыть 2 терминала в каталоге client-server/scala

В первом:
scala run Server.scala

Во втором:
scala run Client.scala


### По умолчанию клиент отправит:
ADD 3 5

Сервер ответит:
8


### Можно передать другие числа:
scala run Client.scala -- ADD 10 20

Ожидаемый ответ - 30. После обработки одного клиента сервер завершится, поэтому для следующего запроса его нужно запустить заново
