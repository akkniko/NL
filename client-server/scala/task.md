Клиент отправляет одну строку. Сервер возвращает количество Unicode code points в ней в формате `LENGTH N`. Нужно считать именно символы Unicode, а не байты UTF-8 и не длину в единицах UTF-16.

**Требования:** использовать стандартный Java API сокетов и `String.codePointCount`; задать тайм-аут подключения на клиенте; корректно обработать пустую строку и отсутствие ответа.

**Проверка:** `Hello, server!` → `LENGTH 14`.
