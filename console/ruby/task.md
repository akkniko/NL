Запросить у пользователя имя и три целых числа — например, результаты трёх контрольных работ. Вывести в консоль введённые данные и среднее арифметическое, затем сохранить тот же отчёт в `report.txt`.

**Требования:**
- запросить и проверить каждое значение;
- при неверном числовом вводе повторить соответствующий запрос или корректно сообщить об ошибке;
- использовать стандартные средства Ruby для консольного ввода и файлового вывода.

**Проверка:** для чисел `4`, `5`, `3` среднее равно `4.0`.
