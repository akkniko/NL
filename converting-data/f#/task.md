Преобразовать файл `config.txt` в `config.json`. Вход содержит пары `key=value`, по одной на строке. Пустые строки и строки, начинающиеся с `#`, игнорируются. Ключи состоят из латинских букв, цифр и `_`, первый символ — буква или `_`. Все значения трактуются как строки.

**Требования:**
- обработать пробелы вокруг ключа и значения;
- корректно экранировать кавычки, обратную косую черту и управляющие символы в JSON-строках;
- отклонять повторяющиеся ключи, чтобы результат не имел неоднозначной структуры;
- использовать только стандартные средства F#/.NET.

**Пример входа:**

```text
# app configuration
host = localhost
mode = development
```

Результат должен быть эквивалентен JSON-объекту `{"host":"localhost","mode":"development"}`.
