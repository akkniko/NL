Прочитать `input.csv`, где первая строка содержит заголовки, а последующие строки — значения ячеек, и преобразовать данные в таблицу Markdown в файле `output.md`.

**Ограничения упрощённого CSV:** поля не содержат запятых или переводов строк внутри кавычек; каждая запись состоит из одинакового количества полей. Это ограничение нужно явно указать в README программы.

**Требования:**
- проверить, что в каждой строке одинаковое число столбцов;
- экранировать символ `|` внутри ячеек, чтобы он не ломал Markdown-таблицу;
- использовать стандартные средства Julia без CSV-пакета.

**Пример результата:**

```markdown
| name | age |
| --- | --- |
| Alice | 20 |
| Bob | 22 |
```
