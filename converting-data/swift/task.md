
Преобразовать файл `input.tsv` (табуляция как разделитель) в XML-файл `output.xml`. Первая строка TSV содержит заголовки столбцов, остальные — записи. Для каждой записи создать элемент `row`, а для каждого значения — элемент `field` с атрибутом `name`, равным соответствующему заголовку.

**Требования:**
- все строки, кроме последней, имеют одинаковое число полей;
- корректно экранировать XML-символы `&`, `<`, `>`, а также кавычки в значениях атрибутов;
- использовать только стандартные средства Swift;
- сохранить текст в UTF-8 и сообщить об ошибке некорректной таблицы.

**Пример структуры результата:**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<rows>
  <row><field name="name">Alice</field><field name="age">20</field></row>
</rows>
```
